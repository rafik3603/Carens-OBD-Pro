# 🚗 تطبيق التشخيص الذكي المتقدم للسيارات (OBD2 & Autocom/Delphi Scanner)

تطبيق أندرويد متكامل ومصمم بأحدث التقنيات (**Kotlin & Jetpack Compose**) يمثل منصة احترافية رائدة لتشخيص أعطال السيارات، قراءة البيانات الحية، وبرمجة الأنظمة المتقدمة. يجمع التطبيق بين مرونة أجهزة **ELM327 (Bluetooth/BLE)** وقوة واجهات الفحص الاحترافية مثل **Autocom / Delphi DS150E** عبر منفذ **USB OTG**، معززاً بالذكاء الاصطناعي **Google Gemini AI** لتوقع الأعطال وتقديم نصائح الصيانة الوقائية.

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. 🔌 توافق ثلاثي ومرونة اتصال كاملة (Triple Connection Support)
*   **البلوتوث التقليدي (Bluetooth Classic):** للاتصال القياسي بمحولات ELM327 SPP الشهيرة.
*   **البلوتوث ذو الطاقة المنخفضة (BLE - Bluetooth Smart):** للاتصال بمحولات الجيل الجديد فائقة السرعة وتوفير استهلاك الطاقة.
*   **منفذ USB OTG (التوصيل السلكي الاحترافي):** يدعم الاتصال المباشر مع واجهات الفحص الاحترافية مثل **Autocom DS150E** و **Delphi CDP+** (عبر شريحة التوصيل التسلسلي CH340 / FTDI)، مما يتيح الوصول لبروتوكولات أكثر عمقاً بالسيارة.

### 2. ⚡ برمجة متقدمة واختبار المشغلات (Advanced Active Tests & Coding)
*   **تطهير قسري لفلتر بيئة الديزل (Forced DPF Regeneration):** مصمم خصيصاً لمحركات الديزل (مثل كيا كارنز محرك D4EA CRDi VGT 2.0)، للتحكم بالسرعة وحرق جزيئات السخام المتراكمة وإعادة ضبط مستشعرات فلتر الشكمان.
*   **ترميز وبرمجة البخاخات الذكي (IMA Injector Coding):** إدخال وبرمجة أكواد معايرة البخاخات (أكواد Delphi IMA ذات 7 أو 8 رموز) في ذاكرة الـ ECU الفلاشية للأسطوانات الأربع لضمان اتساق كميات حقن الوقود.
*   **اختبار حركة مؤشرات الطبلون (Gauge Sweep Test):** تفعيل اختبار المعايرة لجميع مؤشرات العدادات (السرعة، الـ RPM) من الصفر إلى النهاية.
*   **اختبار لمبات التحذير الذكي (Warning Lights Self-Test):** تفعيل محاكاة كافة لمبات التنبيه والتحذير في الطبلون للتأكد من سلامتها.
*   **التحكم الفعال بالمشغلات الكهربائية (Actuator Activation):**
    *   إرسال نبضات فتح وقفل السنترال لوك (Central Lock).
    *   فحص واختبار محرك نافذة السائق الأمامية صعوداً ونزولاً.
    *   تنشيط وفحص تتابع مضخة الوقود (Fuel Pump Relay).
    *   التحكم في سرعات مروحة تبريد الرادياتير (Off / Low / High).

### 3. 🧠 مستشار طبيب السيارة الذكي (Gemini AI Vehicle Health Predictor)
*   دمج مباشر مع نموذج الذكاء الاصطناعي **Google Gemini API**.
*   تحليل بيانات الحساسات الحية فائق الدقة (السرعة، الـ RPM، درجة حرارة سائل التبريد، حرارة ناقل الحركة، جهد الدينامو، ضغط التربو، مستوى السخام في الـ DPF، وعمر الزيت المتبقي).
*   تحليل تفصيلي لأكواد الأعطال (DTC) وتوليد تقرير تشخيصي شامل باللغة العربية يتضمن:
    *   توقع الأعطال المستقبلية بناء على الأنماط الحالية للبيانات الحية.
    *   تحديد مدى خطورة الحالة (خطيرة، متوسطة، طبيعية).
    *   اقتراح خطوات الصيانة والإصلاح التفصيلية بالتسلسل المناسب.

### 4. 📊 قارئ ومحلل الحساسات والبيانات الحية (Real-Time Sensor Dashboard)
*   واجهة تفاعلية تحاكي طبلون السيارات الرياضية بتصميم **Sci-Fi / Cosmic Slate** فائق الأناقة والوضوح.
*   مؤشرات دائرية وأفقية تفاعلية لعرض:
    *   عدد دورات المحرك (RPM) والسرعة الحالية ونسبة فتح بوابات الهواء (Throttle).
    *   مستوى شحن بطارية السيارة وحالة عمل الدينامو (Alternator Failure Simulation).
    *   درجة حرارة المحرك وحرارة قير السيارة (Transmission Temperature) مع نظام تتبع فريد لتجنب الحرارة المرتفعة (Overheating).
    *   عمر الزيت المتبقي وعداد المسافة للموعد القادم لتغيير زيت المحرك.

### 5. 🛠️ ماسح ومترجم أكواد الأعطال الشامل (DTC Scanner & Clearer)
*   فحص شامل لكود كمبيوتر السيارة (ECU) لقراءة الرموز المخزنة والمعلقة (Active & Pending Codes).
*   قاعدة بيانات مدمجة لفك تشفير وتوضيح معاني الأكواد القياسية والخاصة بالمصنعين.
*   إمكانية مسح الأكواد وإطفاء لمبة تشيك إنجن (**Clear Check Engine / DTCs**) لخدمة الصيانة.

### 6. 💻 كونسول ومحطة أوامر OBD2 المباشرة (OBD Terminal Console)
*   نافذة تفاعلية مخصصة للمطورين والمحترفين لإرسال أكواد الـ Hex والأوامر البرمجية المباشرة (مثل `ATZ`, `010C`, `0902`).
*   عرض الاستجابات في الوقت الحقيقي مع سجل متكامل للعمليات (Terminal Logs) باللغتين العربية والإنجليزية لتسهيل عملية فك ترميز الاتصال وتتبع الأوامر.

## 🛠️ التقنيات المستخدمة (Technical Stack)

*   **لغة البرمجة:** Kotlin (كلغة أساسية وحيدة).
*   **واجهة المستخدم:** Jetpack Compose للواجهات التفاعلية الحديثة مع دعم Edge-to-Edge و Material Design 3.
*   **إدارة الحالة:** ViewModel مع Kotlin Coroutines و StateFlow لتحديث البيانات الحية بشكل متزامن فائق السرعة وبأقل استهلاك للموارد.
*   **قاعدة البيانات والتخزين:** Room Database لحفظ تقارير الفحص السابقة وسجل قراءات الأكواد بشكل محلي آمن وموثوق.
*   **الذكاء الاصطناعي:** دمج مباشر مع خوادم Google Gemini API مع معالجة الاستجابات بأمان وموثوقية عالية.
*   **ميزات الهاردوير والاتصال:**
    *   Android USB Host API للتعرف والتخاطب المباشر مع واجهات التسلسل والـ Multiplexers عبر كابل USB OTG.
    *   Android Bluetooth & BLE Client APIs للربط اللاسلكي السلس والموثوق.

## 🚀 طريقة البدء والتشغيل (Quick Start)

1.  **استيراد المشروع:** قم بتحميل أو استنساخ المستودع (Repository) في بيئة Android Studio.
2.  **إعداد مفاتيح الذكاء الاصطناعي:**
    *   افتح لوحة **Secrets** في غوغل إيه آي ستوديو (Google AI Studio) أو ملف البيئة المتغير `.env`.
    *   أضف مفتاح الـ API الخاص بك باسم `GEMINI_API_KEY`.
3.  **توصيل الجهاز والسيارة:**
    *   قم بتوصيل محول الفحص الخاص بك (سواء كان ELM327 Bluetooth أو واجهة Autocom/Delphi عبر كابل USB OTG وتفعيل ميزة الـ OTG بهاتفك).
    *   افتح التطبيق، اختر نوع الاتصال المناسب من التبويب الخاص بالتوصيل (Connection)، وانقر على **ربط سريع**.
    *   استمتع بفحص ذكي، برمجة متطورة، وتحليل فوري لأداء سيارتك!

## 🎨 الهوية البصرية والتصميم (Visual Design)

التطبيق مصمم بطابع **الخيال العلمي المظلم (Cosmic Slate Theme)** مع تباينات حادة عالية الدقة باللون الأزرق الفيروزي والأصفر الفوسفوري لتسهيل القراءة ليلاً وفي ظروف العمل بالورش ومراكز الصيانة. يضمن التوزيع الهندسي المريح وأحجام النقر (Touch Targets) التي لا تقل عن 48dp سهولة وتفاعلية وسرعة فائقة في الانتقال والتحكم بجميع زوايا التطبيق.
